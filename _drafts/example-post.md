This is a draft: files in `_drafts/` never show on the site.

To publish a post, put a markdown file in `_posts/` named `YYYY-MM-DD-some-title.md` (for example `2026-11-10-hello.md`)
with the three-dash block at the top like this one, then commit and push. GitHub builds it in a minute or two.

## Markdown works

- lists
- **bold**, *italics*, [links](https://heath.dog)

> and quotes
