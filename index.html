heath.dog

Tools I'm building for OOTP Perfect Team: measuring how the game turns ratings into results, and using that to build better rosters.

The hub

  • Ellis-Day HUDOne page that links every tool below, with tournament rankings and matchups.in use

Rosters

  • Roster BoardPick your own 26, card by card, from the builder's base.in use
  • Platoon FinderPlatoon partners from your own cards, spot by spot.in use
  • Rebuild ChangesWhat a rebuild would change against the rosters in the game, spot by spot.in use
  • Slot GuideWhich saved roster goes in which tournament slot.in use

Cards

  • Card LookupAny card: grades by tournament and era, and where he plays.in use
  • Collection HealthIdle cards in the collection and what they are worth.in use
  • Pack RipperSimulated pack openings, every pull priced, against what the pack costs.in use

Tournaments

  • Event ReportsA report for every tournament run: results, who hit, who pitched.in use
  • Results LedgerEvery run and how it finished.in use
  • Run DiaryEach run with the notes on what went right and wrong.in use
  • Matchup ScoutOpponents' repeat weak spots.in use
  • Field BookWhat the field plays in each tournament.in use
  • Park BookEach park and who it favors.in use
  • Qualifying trackerChampionship points and where to enter next.in use

In the works

  • Tournament simulatorPlays whole tournaments game by game to find bracket odds and test roster choices. The plate-appearance model is built; the game engine is next.building
